# Әр балаға – бір қадам

«Бастауыш – білім негізі» қалалық байқауына арналған жоба сайты.

**Автор:** Сулеева Молдир Сейсенбековна, бастауыш сынып мұғалімі, Алматы қаласы Алатау ауданы №152 мектеп-гимназия.

## Құрамы
- `index.html` — сайттың басты беті (суреттер ішіне енгізілген)
- `docs/` — құжаттардың беттері (толық оқу терезесі үшін)
- `media/review.mp4` — бейнепікір

## GitHub Pages арқылы жариялау
1. GitHub-та жаңа репозиторий ашыңыз (Public).
2. «Add file → Upload files» батырмасын басып, осы бумадағы барлық файлдар мен бумаларды сүйреп салыңыз. `index.html` репозиторийдің түбірінде тұруы керек.
3. «Commit changes» батырмасын басыңыз.
4. Settings → Pages бөлімінде Source: «Deploy from a branch», Branch: `main`, бума: `/ (root)` таңдап, Save басыңыз.
5. 1–2 минуттан кейін сайт `https://ПАЙДАЛАНУШЫ-АТЫ.github.io/РЕПОЗИТОРИЙ-АТЫ/` мекенжайында ашылады.
